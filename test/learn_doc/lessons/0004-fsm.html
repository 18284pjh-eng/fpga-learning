第 4 课 · 状态机 FSM：让电路记住自己在哪一步

对应教材：《FPGA Verilog 开发实战指南》第 14 章「状态机」 · 平台：野火征途 Pro · 预计 120–180 分钟 · 上一篇：第 3 课 · 按键消抖

本课的胜利：把“按下后等待、再判断松开”的过程画成状态图，写成一个同步有限状态机； 仿真验证短按与长按路径，并上板实现：短按让 LED 翻转一次，长按让 LED 快速闪烁。

〇、开场复习（合上资料答）

  1. 第 3 课的 key_flag 为什么只有一个时钟周期？下游怎样把它变成人眼可见的 LED 翻转？
  2. 消抖计数器数满后为什么停在最大值，而不是继续加到溢出？这对应哪一种“状态”？
  3. 按住 KEY1 不放，消抖模块应该只报告一次按下事件。要区分短按和长按，电路还需要记住什么？

答案核对：事件脉冲由时序逻辑捕获；计数器停在最大值是饱和状态；本课要记住“当前处于等待、按住还是完成”的阶段， 以及按住了多久。把有限的阶段和转移条件写清楚，就是 FSM。

一、先建立硬件思维：FSM 是带记忆的电路

组合逻辑只能回答“现在输入是什么”；寄存器能保存“上一个时钟沿之后的结果”。有限状态机把两者接在一起：

状态

由寄存器保存，例如 IDLE、PRESSED、LONG。状态只在时钟沿改变。

转移

由当前状态和输入决定下一状态，例如在 PRESSED 中，计时未到就继续等待，计时到就进入 LONG。

本课使用的状态图如下。圆圈是状态，箭头上的文字是“输入条件 / 输出事件”。输出事件仍然用一个时钟周期的脉冲表达。

IDLEkey_in == 0PRESSED无

PRESSED计时达到长按阈值LONGlong_pulse

关键边界：状态机不是“软件线程”。所有状态寄存器仍由同一个 sys_clk 驱动； 状态转移只会在时钟上升沿发生。组合逻辑负责计算下一步，时序逻辑负责保存这一步。

二、推荐的三段式 FSM

把职责拆开，波形和综合结果都更容易检查。先记住结构，再填入本课的业务条件：

// 1. 状态寄存器：只保存 current_state
always @(posedge sys_clk or negedge sys_rst_n) begin
    if (!sys_rst_n)
        current_state <= IDLE;
    else
        current_state <= next_state;
end

// 2. 下一状态组合逻辑：只决定 next_state
always @(*) begin
    next_state = current_state;  // 默认自保持
    case (current_state)
        IDLE:    if (key_down) next_state = PRESSED;
        PRESSED: if (released)  next_state = IDLE;
                 else if (long_done) next_state = LONG;
        LONG:    if (released)  next_state = IDLE;
        default:              next_state = IDLE;
    endcase
end

// 3. 输出时序逻辑：脉冲默认清零，只在事件发生时拉高一拍
always @(posedge sys_clk or negedge sys_rst_n) begin
    if (!sys_rst_n)
        short_pulse <= 1'b0;
    else begin
        short_pulse <= 1'b0;
        if (current_state == PRESSED && released)
            short_pulse <= 1'b1;
    end
end

default 分支是硬件安全网：如果寄存器因上电、干扰或仿真初始化进入非法编码，电路会回到已知状态。 next_state = current_state 则避免组合逻辑遗漏条件而推导出不想要的锁存器。

三、实战 A：短按/长按控制器

练习场：test/case/04-key-fsm/，目录沿用前三课的 src/、sim/、sp1_prj/。

  1. 先画状态图和时序图。画出复位、稳定按下、长按阈值、松开四段；标出 short_pulse 与 long_pulse 只出现一拍的位置。
  2. 写 src/key_fsm.v。输入为 sys_clk、sys_rst_n、第 3 课输出的干净 key_flag 或稳定按键电平；输出为 led_out。建议先只完成短按路径，再加长按。
  3. 加入参数。用 parameter LONG_CNT_MAX 控制长按时长。真实板上可按 50MHz 计算，仿真例化时改成 20'd99，不要修改 RTL 中的物理时钟假设。
  4. 连接输出。短按事件让 led_out 翻转一次；进入 LONG 后用一个小分频计数器让 LED 周期闪烁。LED 是寄存器，不要直接接一拍脉冲。
  5. 用文本写工程约束。创建 sp1_prj/key_fsm.qpf 和 key_fsm.qsf，把顶层、器件、Verilog 文件和四个引脚写进去。约束文件是可审查、可复现的工程源文件，不必依赖 Pin Planner。

四、命令行主线：一个 Makefile 串起仿真、编译和下载

沿用第 3 课的 Makefile 习惯，新增 sim/tb_key_fsm.sv，并把 Makefile 放在练习根目录。先定义变量：

MSBIN := /tool/altera/13.0sp1/modelsim_ase/bin
QBIN  := /tool/altera/13.0sp1/quartus/bin
ROOT  := $(CURDIR)
PRJ   := $(ROOT)/sp1_prj
TOP   := tb_key_fsm
SOF   := $(PRJ)/output_files/key_fsm.sof

.PHONY: sim wave quartus sof program clean

quartus_sh --flow compile 会依次完成 Analysis & Synthesis、Fitter、Assembler 和时序分析，输出报告和 .sof：

sim:
	cd sim && $(MSBIN)/vlib work
	cd sim && $(MSBIN)/vlog -quiet ../src/key_fsm.v tb_key_fsm.sv
	cd sim && $(MSBIN)/vsim -c $(TOP) -do "vcd file key_fsm.vcd; vcd add -r sim:/$(TOP)/*; run -all; quit -f"

wave: sim
	gtkwave sim/key_fsm.vcd

quartus:
	$(QBIN)/quartus_sh --flow compile $(PRJ)/key_fsm

sof: quartus
	@test -s $(SOF)

program: sof
	$(QBIN)/quartus_pgm -c USB-Blaster -m JTAG -o "p;$(SOF)"

clean:
	rm -rf sim/work sim/key_fsm.vcd sim/transcript $(PRJ)/db $(PRJ)/incremental_db $(PRJ)/output_files

常用入口是 make sim、make wave、make quartus 和 make program。下载前确认 jtagconfig 能看到 USB-Blaster；program 默认不挂到 all，避免误下载。

4.1 用命令行生成最小 QSF

把下面内容保存为 sp1_prj/key_fsm.qsf：

set_global_assignment -name FAMILY "Cyclone IV E"
set_global_assignment -name DEVICE EP4CE10F17C8
set_global_assignment -name TOP_LEVEL_ENTITY key_fsm
set_global_assignment -name VERILOG_FILE ../src/key_fsm.v
set_location_assignment PIN_E1  -to sys_clk
set_location_assignment PIN_M15 -to sys_rst_n
set_location_assignment PIN_M2  -to key_in
set_location_assignment PIN_L7  -to led_out

引脚分配、顶层实体和器件都在文本中，适合版本控制。GUI 的 Pin Planner 只作为核对工具；真正编译以 QSF 为准。

五、用 Makefile 验证每条路径

沿用第 3 课的 Makefile 习惯，新增 sim/tb_key_fsm.sv。本课 testbench 至少覆盖四件事：

  • 复位后状态为 IDLE，所有事件脉冲为 0。
  • 短按：按下并在阈值前松开，short_pulse 恰好一拍，long_pulse 不出现。
  • 长按：保持超过 LONG_CNT_MAX，只进入一次 LONG，释放后回到 IDLE。
  • 非法状态恢复：用层次引用（仅用于仿真）把状态写成非法值，下一状态应回到 IDLE。

仿真结束时用 $display 打印 PASS/FAIL 并用 $finish 退出。GTKWave 中重点观察： current_state、长按计数器、两个事件脉冲和 led_out。先 Zoom Fit，再量脉冲宽度是否为 20ns。

六、GUI 只保留三种用途

  1. 看波形：make wave 启动 GTKWave；不要依赖 ModelSim GUI。
  2. 核对约束：需要时打开 Quartus 的 Pin Planner，检查 QSF 是否被正确解析。
  3. 观察下载：需要图形化确认时打开 Programmer；日常下载使用 make program。

七、检索练习

1. 三段式 FSM 中，状态寄存器的职责是什么？

状态寄存器是记忆元件，只在时钟沿更新；下一状态和输出的计算由另外的组合或时序逻辑完成。

2. 为什么事件脉冲通常在输出时序块开头默认清零？

每拍先清零，再在满足条件的那一拍置 1，脉冲自然只有一拍。异步输入同步化是另一个问题，需要双触发器等结构。

3. 在组合状态转移块中漏写某个分支，最可能出现什么问题？

组合逻辑必须对所有输入给出结果。默认自保持和 default 分支能减少遗漏，也让非法状态有恢复路径。

八、通关标准与下一课

  1. 仿真中短按、长按、释放三条路径都通过，事件脉冲没有多拍或漏拍。
  2. 上板后短按只翻转一次；长按进入可见闪烁；松开后回到空闲。
  3. 能解释：状态寄存器保存什么、转移条件在哪里、为什么输出脉冲必须被寄存器捕获。

完成后下一步是流水灯：把 FSM 的状态从“按键阶段”换成“LED 序列阶段”，练习状态编码、组合逻辑和多路输出。
