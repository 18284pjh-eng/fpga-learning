第 1 课 · 点亮你的第一盏 LED

对应教材：《FPGA Verilog 开发实战指南》第 9 章「点亮你的 LED 灯」 · 平台：野火征途 Pro（EP4CE10F17C8N） · 预计 60–90 分钟 · 上一篇：（这是第一课）

本课的胜利：不抄代码，独立完成一次「写 RTL → 约束引脚 → 编译 → 下载 → 上板」的完整闭环， 让按下 KEY1 时 LED 点亮。这 5 步是之后 每一课 都要重复的骨架，第一次走通比理解所有细节更重要。

一、先换个脑子：你在描述电路，不是在写程序

你写过 2 年固件，这是优势也是陷阱。野火在书的前言里点名批评的一种失败模式就是 「直直白白 C 思想的嫁接搬移」。先用 30 秒对照表校准一下：

MCU 思维（你的默认模式）

代码是指令序列，CPU 一条条执行。led = key; 是某个时刻执行的一次动作，跑在 main 循环里。

FPGA 思维（本课要建立的）

代码是电路图纸。assign led_out = key_in; 描述的是一根永远存在的导线——没有"执行"，上电即生效，所有语句并行同时工作。

本课的电路简单到只有一根"导线"，但它有真实的物理约束（这些是书中 9.3 节查原理图得到的）：

信号引脚电气事实
key_in（KEY1）PIN_M2按下时为 低电平（0），松开为高（板上有上拉）
led_out（LED）PIN_L7低电平点亮（LED 阳极接电源，FPGA 引脚吸电流）

所以 assign led_out = key_in; 的效果是：按下（key=0）→ led=0 → 灯亮。两个"低电平"正好抵消，一根直连导线即可。 这属于组合逻辑：输出只取决于当前输入，没有时钟参与。

老师提示：先打开征途 Pro 原理图（1-开发板原理图_封装库_尺寸图_硬件手册/EBF EP4CE10 Pro/征途_PRO_EBF410202v1_SCH_20230915_原理图.pdf）， 自己找到 KEY1 和 LED 的电路，确认上面两个极性。会查原理图是固件工程师的旧技能，在 FPGA 世界同样保命。

二、实战五步（边做边勾）

练习场是你已经建好的 /home/pjh/project/fpga_learning/test/01_led/sp1_prj/（目前是空工程）。 官方答案在 2-野火开源图书合集（源代码以及文档）/征途Pro/01_led/——先自己写，卡住了再看。

  1. 先回忆，再动手写 rtl/led.v。 在 test/01_led/rtl/ 下新建 led.v，凭记忆写出模块：一个输入 key_in，一个输出 led_out， 一句 assign 连起来。写完再和官方 rtl/led.v 对照。注意野火的代码风格：文件头注释块、信号对齐、中文行注释。
  2. 把源文件加入工程。 打开 Quartus → Project Navigator → Files，或直接在 led.qsf 里加 set_global_assignment -name VERILOG_FILE ../rtl/led.v。 设置顶层实体为 led（官方写法：TOP_LEVEL_ENTITY led）。
  3. 分配引脚。 菜单 Assignments → Pin Planner：把 key_in 定到 PIN_M2，led_out 定到 PIN_L7。 顺便确认器件是 EP4CE10F17C8。这步在 MCU 里不存在——FPGA 的引脚是你说了算，约束就是图纸上的"接线端子编号"。
  4. 全编译。 Processing → Start Compilation（Ctrl+L）。观察 Task 窗口的流水线： Analysis & Synthesis（把 Verilog 综合成门级网表）→ Fitter（把电路塞进芯片的具体单元并布线）→ Assembler（生成 led.sof）→ Timing Analysis。编译零错误后再继续。
  5. 下载与上板验证。 Tools → Programmer，模式选 JTAG，选 led.sof，Start。 按下 KEY1 → LED 点亮，松开 → 熄灭，即通关。

为什么断电程序就没了？.sof 通过 JTAG 直接写进 FPGA 芯片内部的 SRAM 配置单元，掉电即失。 所以板上有 16Mbit SPI Flash：正式产品用 AS 模式把 .jic 固化进去，上电时 FPGA 从 Flash 自举。这也是 「现场可编程」的含义——配置数据本身就是电路的一部分。

三、检索练习（合上资料答）

1. assign led_out = key_in; 这句话综合出来的是什么？

assign 无时钟、无"执行"，描述的是永远存在的连接——输出随输入实时（纳秒级传播延迟）变化，属于组合逻辑。选"寄存器"的是 always 块里非阻塞赋值干的事。

2. .sof 文件下载后 FPGA 断电，重新上电会发生什么？

JTAG + sof 是纯 SRAM 配置，掉电即失；要固化必须用 AS 模式烧 .jic 到板载 16Mbit SPI Flash。

3. 引脚约束（Pin Planner 里把 key_in 定到 PIN_M2）这一步，本质上是在做什么？

FPGA 封装上的球（F17 = 256-pin FBGA）和外部焊盘的连接是硬件固定的，约束就是指定你的哪个端口接到哪个球。时序约束（频率）是另一套东西，后面课程会讲。

四、通关后的两个思考题（下一课的开场）

  1. 现在 LED 只有"亮/灭"两个状态。如果想让 LED 每 0.5 秒闪烁一次， 固件里你会写 delay 循环——在 FPGA 里没有 CPU，你猜用什么电路来实现"等一段时间"？（提示：板载晶振 50MHz）
  2. 官方工程目录分 rtl / sim / quartus_prj / doc 四层，sim/tb_led.v 是干什么的？ 为什么官方每个实验都带它？（这是下一课的主角：ModelSim 仿真）
