GTKWave 常用操作速查卡

适用：本课程所有 VCD 波形（run_sim.sh 产物） · 2026-09-06

启动与布局

gtkwave 文件.vcd                 # 直接打开
gtkwave led.vcd 布局.gtkw        # 打开波形 + 恢复保存的视图布局
  • 左侧 SST 树：按设计层次浏览，双击信号加入右侧波形区（或选中后点 Append）。
  • File → Write Save File（.gtkw）：把"加了哪些信号、缩放位置、标记"存成布局， 下次打开 VCD 后加载 .gtkw 一键复原。每课保存一份。

缩放与平移（最高频）

操作方式
放大Ctrl+滚轮 或 Alt+滚轮向下（以光标为中心）
缩小Alt+滚轮向上
Zoom Fit（全局适配）工具栏 |<->| 按钮 —— 每次打开波形先按它
横向平移时间轴Shift+滚轮，或直接拖动顶部时间标尺
上下滚信号列表普通滚轮（在信号列表区）
缩放锚点View 菜单 → Center Zoom：让缩放围绕主游标而非屏幕中心

游标与时间测量（本课程的核心用法）

操作效果
左键点波形放置主游标（绿色虚线），顶部时间栏同步显示
中键点击放置基准游标；顶部状态栏显示 主游标−基准 的 delta 差值
鼠标悬停状态栏实时显示 光标位置 与 主游标 的差值
Shift+左键放置命名游标 A、B、C…（Marker 菜单里管理、可跳转）

量 5000ns 的标准动作：Zoom Fit → 左键点 led 第一个上升沿 → 鼠标悬停到下一个上升沿 → 读状态栏 delta ≈ 5000ns。或者：左键点第一沿、Shift+左键点第二沿，读两个命名游标的差。

信号显示技巧

需求操作
改总线进制选中信号右键 → Data Format → Hex / Decimal / Bin / ASCII
把计数器看成模拟曲线右键 → Data Format → Analog（调 Height/Step）—— 看锯齿波计数器一目了然
数信号翻转次数右键 → Show Change Count（验证"翻转了 4 次"直接读数）
隐藏/恢复信号选中按 Delete（只是不显示，数据还在）；Edit → Unshow All 全部恢复
按值搜信号翻转Search 菜单 → Pattern Search（如搜 led==1 的所有时刻）
展开内部信号右侧选中实例（如 u_led_blink），中间栏出现其内部 cnt/cnt_flag，双击加入显示
