# MISSION

## 身份与背景

- 嵌入式软件工程师，固件开发 2 年。
- 熟悉 C、Python；了解 Verilog / SystemVerilog 语法（但未做过完整 FPGA 工程）。
- 熟悉 SPI、I2C、UART 等常见硬件接口。
- 硬件平台：野火「征途 Pro」开发板（Intel/Altera Cyclone IV EP4CE10F17C8N，50MHz 晶振）。
- 工具链：Quartus II 13.0.1（32-bit Web Edition）。

## 为什么学（Mission）

从点亮 LED 开始，循序渐进"玩转"野火 FPGA：建立正确的硬件描述语言设计思想
（描述电路而非写指令），掌握完整的 FPGA 开发流程（设计→仿真→综合→布局布线→
上板验证），最终能独立完成规范的设计项目。

## 成功的样子

- 短期：独立走完一个工程的完整开发闭环（以点亮 LED 为起点），理解每一步工具链在做什么。
- 中期：独立完成计数器、按键消抖、状态机、UART/SPI/I2C 等接口的 FPGA 实现——
  把已有的嵌入式协议知识"翻译"成硬件电路。
- 长期：能独立设计规范、可仿真的 Verilog 工程（参考野火《FPGA Verilog 开发实战指南》全路线，
  直至图像显示、以太网等进阶实验）。

## 教学锚点

- 用户有 2 年固件经验：善用 MCU 类比（寄存器→导线、main 循环→组合逻辑/时钟沿），
  但要警惕"C 思想嫁接"——这是野火书中反复强调的最大误区。
- 用户了解 Verilog 语法：语法不是瓶颈，**设计方法与工程流程**才是重点。
- 从每一课开始都对应野火书的章节，官方例程代码在
  `2-野火开源图书合集（源代码以及文档）/征途Pro/` 下。
